# Electrolab

Site de eletrônica para iniciantes, estudantes e hobbystas: cadastre os componentes que você tem, publique projetos, comente, salve e siga outras pessoas.

## Recursos
- Inventário de componentes com quantidades
- Projetos com fotos, curtidas, comentários e salvos
- Login com e-mail e senha ou com o Google
- Perfis com username, seguir pessoas e foto de perfil
- Denúncias com painel para o moderador

## Tecnologias
HTML, CSS e JavaScript em um único arquivo (`index.html`), com Firebase (login e banco de dados).

## Como publicar (GitHub Pages)
1. Envie estes arquivos para a raiz de um repositório público.
2. No repositório: **Settings → Pages → Deploy from a branch → main / (root) → Save**.
3. Aguarde 1 a 2 minutos. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
4. No Firebase: **Authentication → Settings → Authorized domains → Add domain** e adicione `SEU-USUARIO.github.io`.
